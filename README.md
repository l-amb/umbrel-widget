## Umbrel Custom Widgets
This app store contains two apps for umbrelOS.

### CWidgets
Install custom widgets on your Umbrel, whether it's time, weather, stats or more.

### Custom Background
Use your own video (MP4) or image (PNG, JPG) as the background of the whole umbrelOS dashboard.
Widgets, the dock and Umbrel's accent colours follow along, and you can switch back to Umbrel's own look at any time.

> [!NOTE]
> Custom Background works by adding a small script to the umbrelOS dashboard files, so it needs write access to that folder.
> If an umbrelOS update replaces those files, the app puts its script back automatically.

> [!NOTE]
> Some of this project was generated with AI, However all code has been human reviewed.
